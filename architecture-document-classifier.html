    How the scoring works. Four strands are scored 0–100: text (weighted architecture vocabulary, TF-IDF-style), structure & diagrams (headings, component lists, tables, diagram references), the specification checklist (six items defining “architectural”), and intent (commitment signals — decisions actually made, not topics merely mentioned). The fused score weights them 35 / 20 / 30 / 15. API-reference signals (parameter lists, return types, method signatures) subtract up to 25 points, because a document can mention every component and still not describe an architecture.

    This is a working demonstration of the design proposed in the software-architecture classification thesis — a rule-based stand-in for the planned TF-IDF + hybrid classifier, built so the pipeline, thresholds, and review band can be tried by hand. It is not the trained model, and its scores are not evaluation results.
